# Open-source algorithmic reverbs for vocals: source-level implementation notes (late 2026)

**How to read these notes.** Every number marked *[src]* was read by me directly from the cited source file in a fresh clone made on 2026-11-18 (commit short-hashes are in the licence table in the first section). Anything marked *[secondary]* comes from a search-result summary of a web page that I could **not** open directly: the hosts `airwindows.com`, `valhalladsp.com` and `kvraudio.com` are outside this session's allowed network, so forum/blog statements are lower-confidence paraphrases unless stated otherwise. Airwindows developer notes are the exception: they are quoted from `Airwindopedia.txt`, which ships inside the Airwindows git repository and which I read directly. No constant in this file is invented; where I did not open a function body I say so.

Sample-rate convention used throughout: "N @ F Hz" means the source stores N samples at reference rate F and scales by `fs/F` at run time. To get samples at 48 kHz multiply by `48000/F` (29761 Hz -> x1.61285; 34125 Hz -> x1.40659; 25641 Hz -> x1.87200; 32000 Hz -> x1.5; 44100 Hz -> x1.08844).

### Inferences
- GPL-2.0-or-later code (freeverb3, zita-rev1) can be ported because "or later" lets the project take it under GPL-3.0; a Rust re-implementation that follows the code closely is a derivative work and must keep the copyright notices (Kamogashira, Adriaensen) and the GPL. MIT sources (Airwindows, CloudSeedCore, Aether, Mutable Instruments) need their copyright/permission notice reproduced in the distribution (e.g. a THIRD-PARTY-NOTICES file).
- Constant tables such as delay-length sets are part of the copyrightable expression of those programs in practice; treat the port as a derivative of each source and attribute accordingly, rather than assuming numbers are "free".
- "Best on vocals" consensus cannot be established from what I could reach; the defensible statement is: Dragonfly Room/Hall/Plate (freeverb3 Progenitor2 / zrev2 / NRevB+Dattorro), the Dattorro family (MVerb, Plateau), and Airwindows kPlate/kStation are the open-source reverbs that developers and users most often present as vocal-capable, while Cloud Seed and Galactic/Verbity are presented by their own authors as ambient/special-effect tools.

## Exact topology and constants: delay lengths, coefficients, feedback matrices, damping, modulation, size and sample-rate scaling, stereo decorrelation

### Takeaway
Five distinct architectures cover everything studied: (1) Dattorro/Griesinger figure-eight allpass tank (strev, MVerb, Plateau, MI Clouds, Surge Reverb 2 as a 4-block ring), (2) 8-line Hadamard FDN with per-line allpass and shelving decay (zita-rev1 -> freeverb3 zrev2 = Dragonfly Hall), (3) Lexicon-224-style nested-allpass figure-eight with multi-tap outputs (freeverb3 progenitor2 = Dragonfly Room), (4) parallel, *un-coupled* modulated comb lines each containing an allpass diffuser plus a seeded random multitap/diffuser front end (Cloud Seed), and (5) Airwindows' cascaded "feedforward Householder" banks (4x4x3 in Verbity/Galactic, 5x5x5 in Verbity2/kPlate) with a tiny regeneration gain. All constants needed to rebuild each are below, with file references.

### Cited Findings

#### A. freeverb3 common machinery (used by all Dragonfly algorithms) *[src]*
- Delay scaling: `getTotalFactorFs() = sampleRate * RSFactor`; lengths stored at a reference rate are multiplied by `totalFactor = fs*RSFactor/refFs`. `p_(def,factor)` = `floor(def*factor)` (min 1) then **incremented until prime** (primeMode is on by default); `f_()` is the same without the prime search. Modulation excursions use `fs/refFs` only (not RSFactor). — [revbase.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/revbase.cpp), [revbase_t.hpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/revbase_t.hpp)
- Pre-delay is implemented as a plain integer delay on the **wet output** (`delayWL/delayWR`, `initialDelay = fs*ms/1000`); `getLatency()` returns 0. Width: `wet1 = wet*(width/2+0.5)`, `wet2 = wet*((1-width)/2)`; `outL = fpL*wet1 + fpR*wet2`. — [revbase.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/revbase.cpp)
- Plain allpass: `in += fb*z; out = z - fb*in; store in`. "With decay" variant: `out = decay*z - fb*in`. Modulated allpass (`allpassm`): modulation input in [-1,+1] is mapped to `(mod+1)*modulationsize` extra samples, read with first-order **allpass interpolation** (a linear-interpolated `_process_li` variant also exists); optional per-sample feedback modulation `feedback_mod = feedback + fmod`. — [allpass_t.hpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/allpass_t.hpp)
- Lowpass-feedback comb: `out = buf[i]; filterstore = out*damp2 + filterstore*damp1; buf[i] = in + filterstore*feedback`. Feed-forward comb used for output "spin": `out = buf[i]*feedback + in; buf[i] = in`. — [comb_t.hpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/comb_t.hpp)

#### B. Dragonfly Hall = freeverb3 `zrev2` ("Hibiki"; zita-rev1 FDN + input diffusion + shelving decay + modulation) *[src]*
- Eight lines. Total loop times in **seconds** (comment "[s] ~70[m]"): `{.153129, .210389, .127837, .256891, .174713, .192303, .125000, .219991}`; allpass part of each line: `{.020346, .024421, .031604, .027333, .022904, .029291, .013458, .019123}`. Each line = modulated allpass of `Diff[i]*fs*RS` samples followed by a modulated delay of `(Total[i]-Diff[i])*fs*RS` samples (both prime-rounded); modulation excursion `delay_EXCURSION = 0.001` s (`0.001*fs` samples) on both. — [zrev.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev.cpp)
- Per-line gain: `sqrt(1/8) * 10^(-3*(delaySize+diffSize)/(rt60*fs))`. In-line allpass coefficient `apfeedback` with **alternating sign** per line (+,-,+,-,...). Base-class defaults: `rt60=2.0, apfeedback=0.6, loopdamp=3600, outputlpf=10000, outputhpf=4, dccutfq=2.5, lfo1freq=0.9, lfo2freq=1.3, lfofactor=0.31`. — [zrev.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev.cpp)
- Mixing matrix: unnormalised 8x8 Hadamard done as three butterfly stages `(0,1)(2,3)(4,5)(6,7)`, then `(0,2)(1,3)(4,6)(5,7)`, then `(0,4)(1,5)(2,6)(3,7)` (each `t=a-b; a+=b; b=t`); the `sqrt(1/8)` in the line gain normalises it. — [zrev2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.cpp)
- zrev2 additions: (a) input diffusion = **10 series modulated allpasses per channel**, lengths @ 34125 Hz L `{617, 535, 434, 347, 218, 162, 144, 122, 109, 74}`, R `{603, 547, 416, 364, 236, 162, 140, 131, 111, 79}`, coefficient `-idiff1` (default 0.78), excursion `allpM_EXCURSION/3 = 32/3` (integer division -> 10) samples @ 34125 Hz, modulated by LFO1 on L and inverted LFO2 on R with the sign alternating per stage; (b) the one-pole loop damper of zrev is replaced by an RBJ **low shelf at `rt60_xo_low` and high shelf at `rt60_xo_high`** (slope 1) inside each line, placed on the line's input (`_diff1[i]( _lsf0[i]( _hsf0[i]( delayOut + input )))`). Shelf gain in dB = `R2dB(10^(-3*L/(rt60*fs) / f * (1-f)))` with `f = rt60_factor_low` or `_high`, which makes the band's decay time exactly `rt60*f`. Defaults: `rt60_f_low=1.3, rt60_f_high=0.3, xo_low=500 Hz, xo_high=3600 Hz, idiff1=0.78, wander=22 ms, spin=2.4 Hz, spin_factor=0.3`. — [zrev2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.cpp), [zrev2.hpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.hpp)
- Signal routing per sample: `outL,outR = dccut(in)` -> 10 input allpasses each -> lines 0,1 get `+L`, lines 2,3 get `-L`, lines 4,5 get `+R`, lines 6,7 get `-R` -> allpass(shelves(delayOut + in)) -> Hadamard -> write to delays with LFO modulation (allpasses use lfo1 on lines 0-3 and lfo2 on 4-7 with alternating polarity; delay writes use the pattern lfo2q, lfo1q, lfo2p, lfo1p, lfo1p, lfo2q, lfo1p, lfo2q). Output taps (post-Hadamard): `outL = 0.2*(x0 - x1 + x2 - x3)`, `outR = 0.2*(x4 + x5 - x6 - x7)`. — [zrev2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.cpp)
- LFOs are complex-rotation sine oscillators multiplied by `lfofactor`, then low-passed by a 1st-order Butterworth at the LFO's own frequency. Output "spin/wander": each output passes a feed-forward comb of length `wander` ms whose tap gain is a third LFO (`spin` Hz, x `spin_factor`, low-passed), with opposite sign on L and R -> slow amplitude-modulated 22 ms echo that decorrelates the channels. Then output HPF -> LPF -> pre-delay. — [zrev2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.cpp), [efilter_t.hpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/efilter_t.hpp)
- Dragonfly Hall wrapper mapping: Size (10-60 m) -> `late.setRSFactor(size/80)` and `early.setRSFactor(size/10)`; Diffuse % -> `idiffusion1 = apfeedback = diffuse/140`; Low Cut / High Cut -> output HPF/LPF of both early and late; Low Cross, Low Mult (0.5-2.5x), High Cross, High Mult (0.2-1.2x) -> shelf crossover/factors; Spin (0-10 Hz); Wander (0-40 ms); Decay 0.1-10 s; Modulation % -> `spinfactor = lfofactor = mod/100` (0 is replaced by 0.001); pre-delay 0-100 ms (values < 0.1 ms forced to 0.1). Late input = `early_send * earlyOut + dryInput` (default early_send 0.20). Early block: `loadPresetReflection(FV3_EARLYREF_PRESET_1)`, width 0.8, LR delay 0.3 ms, LR-cross allpass 750 Hz (bw 4), diffusion allpass 150 Hz (bw 4). — [dragonfly-hall-reverb/DSP.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-hall-reverb/DSP.cpp), [DistrhoPluginInfo.h](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-hall-reverb/DistrhoPluginInfo.h)

#### C. freeverb3 `earlyref` (Dragonfly early reflections) *[src]*
- Structure: one tapped delay line per channel; `wet = sum(gain[i] * line.at(delay[i]))`; then `out = outLPF(outHPF(allpass2( wet1*wetSame + wet2*allpassX( delayLR( inputOther + wetOther )))))` where `allpassX` is an RBJ 2nd-order allpass at 750 Hz (bw 4 octaves), `allpass2` an RBJ allpass at 150 Hz (bw 4), and `delayLR` is a cross-channel delay (class default 0.3 ms; note `setFsFactors()` re-sets it to 0.2 ms on every sample-rate change). Tap times are in seconds and scale with `fs*RSFactor`. — [earlyref.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/earlyref.cpp)
- Preset 1 (the one Dragonfly Hall and Room load), 6 taps: delay L `{0.0199, 0.0354, 0.0389, 0.0414, 0.0699, 0.0796}` s, delay R `{0.0209, 0.0364, 0.0399, 0.0424, 0.0709, 0.0806}` s, gain L `{1.020, 0.818, 0.635, 0.719, 0.267, 0.242}`, gain R `{1.021, 0.820, 0.633, 0.722, 0.187, 0.243}`. — [earlyref.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/earlyref.cpp)

Presets 11-22 (10-13 taps per side, 2-85 ms, signed gains 0.14-1.02) are also in the file and are what the stand-alone Dragonfly Early Reflections plugin exposes as programs. — [earlyref.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/earlyref.cpp)

#### J. Cloud Seed (CloudSeedCore 2.0, MIT): seeded multitap + allpass diffuser + parallel modulated comb lines *[src]*
- Two completely independent `ReverbChannel` objects (L and R); no audio crosses between them inside the reverb. The only coupling is the input mix: `cm = InputMix*0.5; Lin = L*(1-cm) + R*cm` (and mirror). — [ReverbController.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/DSP/ReverbController.h)
- Per-channel chain: optional 1-pole high-pass ("Low Cut", 20-1000 Hz) and 1-pole low-pass ("High Cut", 400-20000 Hz) -> noise gate (`n*n < 1e-9 -> 0`) -> pre-delay (0-500 ms) -> optional **multitap delay** -> optional **early allpass diffuser** (1-12 stages) -> this signal is the "Early" output and also feeds `LineCount` (1-12) parallel **delay lines**; line outputs are summed and scaled by `1/sqrt(lineCount)`; `out = dry*in + early*earlyBuf + late*lineSum`. — [ReverbChannel.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/DSP/ReverbChannel.h)
- A delay line is a **self-feedback comb with processing in the loop** (lines are *not* mixed through a feedback matrix): `x = in + feedback*loopOut(previous block)` -> modulated delay -> [output tap if LateMode = PRE] -> optional allpass diffuser (1-8 stages) -> optional low shelf -> optional high shelf -> optional 1-pole low-pass -> stored as loop output -> [output tap if LateMode = POST]. — [DelayLine.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/DSP/DelayLine.h)
- Block-size dependence: the loop output is pushed into a `CircularBuffer<2*BUFFER_SIZE>` and popped at the start of the *next* call, so the true loop time is `delaySamples + bufSize` of whatever block size the host passes (up to `BUFFER_SIZE`, 1024 in the README). The decay formula below ignores that extra block. — [DelayLine.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/DSP/DelayLine.h), [Readme](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/Readme.md)

The in-loop diffuser of line `i` is seeded with `postDiffusionSeed * (i+1)`. — [ReverbChannel.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/DSP/ReverbChannel.h)

#### K. Airwindows (MIT): cascaded Householder banks, tiny regen, undersampling, built-in saturation *[src]*
- Common pattern. Every "reverb sample": write `input + feedback*regen` into bank 1's delays; read them; write a Householder mix of those outputs into bank 2's delays; ... the last bank's outputs are mixed once more to form the feedback values and are summed for the output. 4-line banks use `y_i = x_i - (sum of the other three)` (= 2x a 4x4 Householder reflection); 5-line banks use `y_i = 3*x_i - 2*(sum of the other four)` (= 5x a 5x5 Householder reflection). The mixes are deliberately un-normalised, so the loop only becomes lossless when `regen` equals the reciprocal of the accumulated gain: `0.125 = 1/2^3` for three 4x4 banks, `0.00032 = 1/5^5` for five 5x5 banks - exactly the maximum regen values in the code. — [GalacticProc.cpp](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/Galactic/GalacticProc.cpp), [Verbity2Proc.cpp](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/Verbity2/Verbity2Proc.cpp), [kPlateAProc.cpp](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kPlateA/kPlateAProc.cpp)

The output sample is then copied into a second SIMD lane that runs through the same 16 allpasses (with opposite-sign gains) before being pushed into the long feedback delay, so one trip round the loop crosses 32 allpass stages. Long delay `= 1000 + size*0.099*fs` samples plus `chaos^3 * rand * 0.07 * delay`; `feedbackGain = 0.001^(delay/(T60*fs))`, `T60 = 0.5 * 9^(0.95*decay - 0.7*(1 - size^2))` s (range constants `lowT60 = 0.5`, `highT60 = 4.5`); damping LPF `4000 * 4.5^(1 - damping)` Hz (4-18 kHz); reflection network = 4 delays `0.07, 0.17, 0.23, 0.29` s x size (3rd-order Lagrange), Householder (`-2/4`), per-delay feedback `0.001^(d/(T60*fs)) * 0.23 * mix * (0.735 + 0.235*size)`, then a shelf at 800 Hz with gain `-1 - 9*damping` dB; shake = half-sine burst of 0.5-1 ms x `(1 + 0.5*size)`, amplitude 2. — [SpringReverbProc.cpp](https://github.com/surge-synthesizer/surge/blob/main/src/common/dsp/effects/chowdsp/spring_reverb/SpringReverbProc.cpp), [ReflectionNetwork.h](https://github.com/surge-synthesizer/surge/blob/main/src/common/dsp/effects/chowdsp/spring_reverb/ReflectionNetwork.h), [SchroederAllpass.h](https://github.com/surge-synthesizer/surge/blob/main/src/common/dsp/effects/chowdsp/spring_reverb/SchroederAllpass.h), [SpringReverbProc.h](https://github.com/surge-synthesizer/surge/blob/main/src/common/dsp/effects/chowdsp/spring_reverb/SpringReverbProc.h)
- Surge "Nimbus" is the Mutable Instruments Clouds granular processor wrapped via `sst/effects/NimbusImpl.h`; its reverb is the Clouds reverb in section H. — [NimbusEffect.cpp](https://github.com/surge-synthesizer/surge/blob/main/src/common/dsp/effects/NimbusEffect.cpp)

#### Cross-cutting answers (size, sample rate, modulation, damping, stereo) *[src, summarised from the items above]*
- Size control: freeverb3 multiplies every delay/allpass length by `RSFactor` and re-rounds to primes (Hall: size/80 of a ~70 m table; Room: size/10) and compensates decay gains for the new lengths; MVerb multiplies tank times by `0.05..1.0` and leaves the decay coefficient alone (RT changes with size); Plateau scales tank times by `timeScale` but leaves output taps unscaled; Cloud Seed sets a base line length 20-1000 ms and each line is 0.5-1.5x of it with exact RT60 compensation; Airwindows multiplies fixed prime tables by `size` (or has no size control at all in the k-series); Surge Reverb 2 multiplies all times by `2^roomsize` and recomputes decay from the loop time.
- Sample rate: freeverb3 = reference-rate tables (25641 / 29761 / 34125 Hz) scaled by `fs/ref` then prime-rounded; zita/MVerb/Surge/Cloud Seed/spring = times in seconds or ms x fs; Plateau and MI Clouds = sample tables at 29761 / 32000 Hz scaled linearly; Freeverb and Airwindows = raw sample counts at 44.1 kHz (Airwindows undersamples above 88.2 kHz instead of rescaling).
- Stereo from mono: zrev/zita inject the same mono signal into lines 0-3 and 4-7 and take two different signed sums of the Hadamard outputs; Dattorro variants mono-sum the input and read two different 7-tap sets from the single tank; progenitor2 uses different L/R allpass tables plus 40% diffused cross-feed and 15 signed taps per side; nrev/Freeverb offset every right-channel length by a spread (13 @ 25641 Hz / 23 @ 44.1 kHz); Cloud Seed runs two independent channels with complementary random seeds; Galactic adds a quadrature-vibrato pre-delay and cross-channel feedback; Surge Reverb 1 pans 16 taps across the field; Surge Reverb 2 reads different L/R tap times from the same four delays.

### Inferences
- Because Cloud Seed's lines are independent feedback combs, its echo density comes entirely from the diffusers (up to 12 allpass stages in front and up to 8 inside every loop) rather than from a mixing matrix. That explains both its strength (very dense, "cloud"-like, chorused tails) and why its author calls it a special effect: with few lines and little diffusion it is literally a set of modulated combs.
- The Airwindows "regen" constants look tiny (about 0.0003) only because the cascaded Householder mixes are un-normalised (gain 5 per 5x5 bank). A Rust port can either keep the original scaling (bit-faithful, but internal levels are ~3000x larger than the input, fine in f64) or normalise each bank by 1/5 and use regen/0.00032 as an ordinary 0..1 loop gain; the two are mathematically equivalent only if the in-loop saturation and filters are moved consistently, so for kPlate the safe route is to keep the original scaling.
- Airwindows tables are tuned at 44.1 kHz sample counts and run unscaled at 48 kHz, so a kPlate at 48 kHz is ~8% "smaller" than at 44.1 kHz by design ("slight changes in delay times" in the source comment). To make the DAW sound identical at 44.1/48/96 kHz one must either run the core at a fixed internal rate (resampling, which adds latency unless a zero-latency interpolator like Airwindows' linear one is accepted) or scale the tables by `fs/44100` and re-round to primes (no latency, slightly different mode pattern). The same choice applies to Freeverb.
- freeverb3's prime rounding means the exact integer lengths differ per sample rate and per size setting; a faithful port needs `p_()` (next-prime search) at parameter-change time, not per sample. It allocates when sizes change, so the Rust version should pre-allocate each buffer for the maximum size (largest RSFactor x highest sample rate) and only move indices.
- Modulation interpolation differs by family: freeverb3 uses allpass interpolation (flat magnitude, good for in-loop use), Cloud Seed/Galactic/Surge use linear interpolation (adds slight HF loss that acts as extra damping), the chowdsp spring uses Thiran and Lagrange. For a vocal reverb at 48 kHz, linear interpolation inside a feedback loop audibly darkens long tails; allpass or cubic is the safer default.
- MVerb's early-reflection taps are almost certainly not what its author intended (the loudest taps arrive latest because offsets are measured from the write head). A port can either reproduce the quirk for fidelity or use the intended times; freeverb3's `earlyref` preset 1 uses the same intended numbers (19.9, 35.4, 38.9, 41.4 ms ...) with proper delay semantics.

## What makes a plate vs room vs hall vs chamber different in these implementations (echo-density build-up, early reflections, modal density, damping)

### Takeaway
In the code, the "type" is mostly decided by four things: whether there is a discrete early-reflection stage, how long the recirculating delays are, how much series-allpass diffusion sits in front of / inside the loop, and how decay varies with frequency. Plates = no early reflections, short pre-delay, instant density, bright with HF-only damping; rooms = explicit early taps + short nested-allpass loops + short decay; halls = early taps + long (125-257 ms) FDN lines + multiband decay with longer lows and shorter highs + slow modulation; chambers are approximated by dense series allpasses with short delays and no distinct early pattern.

### Cited Findings
- Dragonfly Plate has **no early-reflection stage at all**: the plugin runs one of nrev / nrevb / strev on the high- and low-cut-filtered input and mixes dry + wet. Its factory decays are 0.2-1.0 s and pre-delays 0-20 ms. — [dragonfly-plate-reverb/DSP.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-plate-reverb/DSP.cpp), [plate DistrhoPluginInfo.h](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-plate-reverb/DistrhoPluginInfo.h)
- The default Dragonfly plate algorithm ("Nested" = nrevb) gets its density from **18 parallel combs per channel** (6 + 12, lengths 1257-2509 samples @ 25641 Hz = 49-98 ms) followed by 8 series allpasses; density is therefore high from the first few tens of ms, with no size control. — [nrevb.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/nrevb.cpp), [nrev.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/nrev.cpp)
- The Dattorro plate ("Tank") has 4 short input allpasses (142/107/379/277 @ 29761 Hz = 4.8/3.6/12.7/9.3 ms), then a single figure-eight loop whose four delays are 106-150 ms and whose four allpasses are 22.6-89 ms; damping is a one-pole low-pass per half loop (HF only), and output is 7 signed taps per side. — [strev.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/strev.cpp)
- Dragonfly Room and Hall both prepend the tapped-delay early-reflection model (preset 1: six taps per side between 19.9 and 80.6 ms, gains 1.02 down to 0.19) and feed 20% of it (default "early send") into the late reverb; Room defaults to sizes 8-15 m with decays 0.2-1.0 s, Hall presets use sizes 10-50 m with decays 0.6-3.8 s. — [earlyref.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/earlyref.cpp), [room DistrhoPluginInfo.h](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-room-reverb/DistrhoPluginInfo.h), [hall DistrhoPluginInfo.h](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-hall-reverb/DistrhoPluginInfo.h)
- The Room late algorithm (progenitor2) is dominated by **nested allpasses** (a double-nested and a triple-nested allpass in each half loop, allpass lengths up to 2032 samples @ 34125 Hz = 59.5 ms, plain delays as short as 1-16 samples) and a bass-boost path (low-passed copy of the cross-fed loop signal, 500 Hz default) rather than HF/LF decay multipliers; damping is a single low-pass in each half loop plus an output low-pass. — [progenitor.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/progenitor.cpp), [progenitor2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/progenitor2.cpp)
- The Hall late algorithm (zrev2) uses eight long lines (125-257 ms at the nominal ~70 m table, scaled by size/80) with an explicit **three-band decay**: low shelf and high shelf inside every line set RT(low) = RT x 1.1...2.5 and RT(high) = RT x 0.2...0.8 in the factory presets, with crossovers at 200-750 Hz and 2.8-7.9 kHz. — [zrev2.cpp](https://github.com/michaelwillis/dragonfly-reverb/blob/master/common/freeverb/zrev2.cpp), [hall DistrhoPluginInfo.h](https://github.com/michaelwillis/dragonfly-reverb/blob/master/plugins/dragonfly-hall-reverb/DistrhoPluginInfo.h)
- zita-rev1 (the hall prototype) hard-wires HF decay: the per-line filter is solved so that reverb time at the "HF damping" frequency is half the mid reverb time, and has an independent low-frequency RT with a crossover (defaults: RT low 3.0 s, RT mid 2.0 s, crossover 200 Hz, damping 3 kHz). — [zita-rev1 reverb.cc (mirror)](https://github.com/royvegard/zita-rev1/blob/master/source/reverb.cc)
- Airwindows encodes "type" in the delay tables: its source comments label the sets by time span and nominal venue - kPlateA tank "86 ms, 882 seat hall" (25 primes of 5-829 samples), kChamberAR "1 to 40 ms, 52 seat room" (3-383 samples), kStation "1 to 93 ms, 272 seat club", kWoodRoom "1 to 90 ms, 249 seat club", kCathedral "16 to 153 ms, 860 seat hall" (11-1395 samples) with an extra `vlfpredelay` of 3275 samples, kCosmos "38 to 188 ms, 1538 seat hall". — [kPlateA.h](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kPlateA/kPlateA.h), [kChamberAR.h](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kChamberAR/kChamberAR.h), [kStation.h](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kStation/kStation.h), [kCathedral.h](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kCathedral/kCathedral.h), [kCosmos.h](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kCosmos/kCosmos.h)
- kPlate's plate character also comes from non-reverb elements: an input high-pass (comment "600hz highpass on input"), 2-sample averaging low-passes, a 3x3 block of nine 0.5-coefficient allpasses instead of discrete early reflections, and soft saturation before and inverse-saturation after the tank. — [kPlateAProc.cpp](https://github.com/airwindows/airwindows/blob/master/plugins/LinuxVST/src/kPlateA/kPlateAProc.cpp)
- Cloud Seed's "Dark Plate" program reaches a plate-like result with early stages disabled (no multitap, no early diffuser), 12 lines of about 96 ms base length (each 0.5-1.5x), 4 in-loop allpass stages (31.6 ms base, feedback 0.85), a 4.8 s line decay, a 340 Hz input low-cut and an in-loop high shelf of -4.6 dB at about 4.5 kHz (values computed by me from the normalised program with the scaling functions in `Parameters.h`). — [Programs.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/Programs.h), [Parameters.h](https://github.com/GhostNoteAudio/CloudSeedCore/blob/master/Parameters.h)
- *[secondary]* Valhalla DSP's reverb-type glossary: a chamber "will have a fast attack, and a quick build of echo density, but without the distinctive early reflections and resonances found in a room reverb"; a hall is "bigger and longer than a Room reverb". — [Valhalla Effect-O-Pedia: Reverb Types](https://valhalladsp.com/2018/05/14/effect-o-pedia-reverb-types/) (search summary; page not opened)
- *[secondary]* Valhalla DSP on physics: "a reverb chamber will have a higher modal density than a plate"; the resonance density of a chamber "will increase with the square of frequency", while plates "have a roughly uniform resonance density with regards to frequency"; chamber-style algorithms "exploit the artifacts of multiple allpass delays in series". — [Valhalla: Chambers and Plates](https://valhalladsp.com/2017/05/23/chambers-and-plates-and-bears-oh-my/), [Valhalla VintageVerb: The Modes](https://valhalladsp.com/2023/02/10/valhallavintageverb-the-modes/) (search summaries; pages not opened)

### Inferences
- A practical recipe that matches the sources: **plate** = mono-summed input, band-limit, short allpass diffusion, immediately dense loop (Dattorro tank or many combs), HF-only damping, pre-delay as a separate user control, optional saturation; **room** = signed early taps (2-85 ms) + nested-allpass loop with short decay (0.2-1 s) and a little low-frequency lift; **hall** = early taps + pre-delay 4-20 ms + long-line FDN with RT(low) > RT(mid) > RT(high) + slow (about 1-3 Hz) low-depth modulation; **chamber** = no distinct early taps, many series allpasses (zrev2/progenitor2's 10-stage input chain, or Cloud Seed's diffuser) into medium-short lines, moderate decay (0.8-1.5 s), flatter frequency-dependent decay than a hall.
- None of the open reverbs read here is a dedicated, well-regarded "chamber" model: Dragonfly's "Small/Large Chamber" are just Hall presets (size 16-20 m, decay 0.8-1.0 s, low mult 1.1-1.3, high mult 0.25-0.35), and Airwindows' kChamberAR is described by its author as a failed chamber. A chamber mode for the DAW would therefore be a *preset/variant* of the hall or room engine, not a separate port.
- Modal density in practice scales with total delay memory in the loop: zrev2 at full size has about 1.46 s of line memory (sum of the eight totals), Dattorro about 0.75 s (sum of the eight loop elements at 29761 Hz), kPlateA's 25 delays total only a few hundred ms. Short total memory + high gain per pass is what gives plates their slightly metallic, "uniform" resonance; long memory gives halls their smoother low end.

- The Valhalla statements are from search-engine summaries; exact wording and context should be re-checked on valhalladsp.com when that host is reachable.
- I did not measure echo-density build-up or modal density (no impulse responses were rendered in this session); the statements above are structural readings of the code.

## Typical vocal settings: pre-delay, decay times, send/return filtering, and what the source presets use

### Takeaway
The vocal-labelled presets in the sources are more conservative than the "20-120 ms pre-delay" folklore: Dragonfly's vocal presets use 0-12 ms pre-delay, decays of 0.3-1.0 s (rooms) and 0.8-2.4 s (halls), high cuts of 5.8-6.25 kHz and high-frequency decay multipliers of 0.30-0.40.
